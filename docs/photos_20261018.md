# 実機写真

ツインファミコン、ブラウン管テレビ、FC-MAGICONを組み合わせた製作者提供の写真。2026-10-18掲載。

## ツインファミコンとブラウン管での表示

![ツインファミコンにFC-MAGICONを挿し、ブラウン管にブルーアーカイブの映像を表示した実機構成](images/20261018/twin-famicom-crt-setup.jpg)

FC-MAGICONを挿したツインファミコンとORIONのブラウン管テレビ。手前はファミリーベーシックキーボード。

## カートリッジの外観

![ラベルを貼った白いFC-MAGICONカートリッジと、開口部から見えるCore2350B2](images/20261018/fc-magicon-cartridge-front.jpg)

白いケースに光沢紙のラベルを貼ったカートリッジ。Core2350B2、BOOTSEL／RESET、音量調整、デバッグ端子の位置が分かる。USB用のフラットケーブルも引き出している。

## ブラウン管で見るカラー映像

![ブルーアーカイブのキャラクター映像をブラウン管にカラー表示した接写](images/20261018/crt-color-display-closeup.jpg)

ブラウン管画面の接写。FC向けに変換したカラー映像の輪郭や濃淡が見える。

## USB映像テストと周辺機器

![NO AUDIO TEST 2の色帯を表示したブラウン管と、ツインファミコン、キーボード、SFCマウス、FCパッド](images/20261018/usb-video-test-setup.jpg)

音声を停止して画像転送を切り分けた際の「NO AUDIO TEST 2 / USB / VIDEO ONLY」。手前にはファミリーベーシックキーボード、スーパーファミコンマウス、FCパッドを配置している。この色帯の写真は音声なしの診断時のもの。
