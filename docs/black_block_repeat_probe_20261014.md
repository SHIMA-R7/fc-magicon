# 黒い矩形の比較テスト

改善版を変更せず保存し、同じcold boot再生ファームウェアにテスト用の映像データだけを結合した。出力は `firmware/out-standalone-video/black-block-repeat-4fps-cold-20261014.uf2`。SHA256 `d902352c2b44bcda7c5fbebc1a3b0f741460820c0fe446c43690de1179ed65c8`。

## 再生内容（4fps、24秒）

| 再生位置 | 内容 |
|---|---|
| 0〜3秒 | 元PV22.75秒の同一画像を毎フレーム転送。見える絵は変えず、表示バンクは交互に切り替える |
| 3〜21秒 | 元PV21.25〜24.00秒の12フレームを6回繰り返す |
| 21〜24秒 | 最初と同じ画像を毎フレーム転送 |
| 24秒以降 | 最後の画像のまま、転送しない |

音声は無音PCM8だが通常の音声PIO/DMA処理は動かす。他の条件をできるだけ維持するため、再生エンジンは変更していない。

原本映像レコードのCHR・ネームテーブル・パレットをそのまま取り出しており、新たな減色やタイル削減は行わない。96レコードの出力一致、CRC、Cと6502による7-VBlank切り替え、音声リングの検査を通過。結合UF2からのデータ再構成も一致。

## 比較方法

参照動画：`firmware/sim/standalone-video-20261014/black-block-repeat-4fps-reference.mp4`。参照静止画：同ディレクトリの `black-block-repeat-hold.png`。実機録画ではない。

- 最初の同一画像表示中に黒い矩形が出入りする場合は、映像の内容変化そのものを原因から外せる。
- 24秒以降に止まると崩れが消える場合は、転送・切り替え処理を優先して調べる。
- 毎回同じ場面・同じ場所で崩れる場合も、変換不良と即断しない。参照画像との一致や再現性を確認する。
- 一度も出ない場合、以前の録画が同じファームウェア・保存データだったかと、連続再生時間等の条件を確認する。

現時点ではテスト版を生成した段階で、実機には未書き込み。現行cold boot版はUSBデバイスを無効化しているので、次回書き込みにはBOOTSEL操作が必要。
