# 点模様を増やさず、タイル境界を減らす比較版

2026-10-17。混色ディザ版は実機でのノイズ増加と一部シーンの見え方を理由に不採用。ユーザーの「もっと四角を減らす方針」に対して、旧成功版の色を保った別候補を作成する。

## 変更範囲

99秒・792コマ・8fps・4:3全画面、旧版の場面ごとのパレット、各16×16区画のパレット選択、音声バイト列、RP2350再生ファームを維持。点模様・混色ディザは追加しない。

変更するのは8×8タイルを最大256パターンへ近似する処理だけ。未間引きの単色量子化画像を目標に、画素誤差に加えてタイル平均色・内部の輪郭・四辺のつながりを評価する。辞書選択後にも隣のタイルを見ながら割り当てを3回調整する。チェッカーボード順の更新で同時更新の隣接を避ける。

採用条件は、原画との差分に現れた8ドット境界の段差指標が旧版より3%以上低下し、原画との画素Lab二乗誤差増加が3%以内であること。条件を満たさないコマは旧版をそのまま保持する。指標の低下が主観的な見やすさを保証するわけではない。コマごとの採用なので、時間方向の安定性は別途実機で評価が必要。

## 制限

16×16属性区画の色制限と256タイル制限自体は変わらない。すべての四角い色境界を消す方式ではない。実機で報告されたノイズ増加の原因は未確定で、この変換が電気的・タイミング的な問題を修正するとは扱わない。

## 検証結果

全792コマ中451コマを変更。採用後の全コマ集計で境界の段差指標は5.1684%低下し、画素Lab二乗誤差は0.2331%増加した。主観的な画質向上率ではない。旧版と全コマの属性64バイト・パレット32バイトが完全一致し、音声領域もバイト単位で一致することを確認。

実際のCパーサー・カート処理＋6502モデルで792コマの完成フレーム切替、最大1779 CPUサイクル、PCMリング、起動待機、高速応答、99秒のサンプルクロック同期を検査し通過。モデルでのA/V誤差最大8.55msは実機測定値ではない。
