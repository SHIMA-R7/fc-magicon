# FC-MAGICON 使い方(手順書)

FC-MAGICON(RP2350B のファミコン用カセット)を実際に使う時の手順。2026-09-27 時点。**基板は未製作・実機では未検証**(PC の試験台 sim では確かめてある)。

## 必要なもの

| もの | 内容 |
|---|---|
| ファミコン本体 | HVC-CPU-07(動くもの)。拡張端子はキーボードを使う時だけ |
| FC-MAGICON 基板 rev0.2 | 部品を付けたもの。R1 は裏面、Q1 は下へ倒して付ける |
| Waveshare Core2350B2 | 基板のソケットに挿す。付属の FPC-USB アダプターと FPC ケーブル |
| PC | Windows 11、Python 3(Pillow・numpy)、picotool(`C:\Users\Yugo\pico`) |
| 1コン | 本体付属。リモートデスクトップではマウスの代わり |
| ファミリーベーシックのキーボード | HVC-007。リモートデスクトップで文字を打つ時だけ(無くても動く) |

## 安全のための決まり

- **ファミコンの電源を切ってから** カセットを抜き差しする。
- USB だけつないで本体の電源が切れている時、カセットはバスに何も出さない(本体の 5V を GPIO46 で見て、来るまで待つ)。USB をつないだまま本体の電源を入れてよい。
- ミラーリングのジャンパー **JP1・JP2・JP3 は1つだけ** 閉じる。2つ以上閉じると信号どうしがぶつかる。
- Core2350B2 はソケットの向きを確かめてから挿す(基板のシルク「Core2350B」と FPC の位置に合わせる)。

## はじめて使う前の準備

### ミラーリングのジャンパー

**JP1(MCU)を推奨**。ゲームごとのミラーリングをファームウェアが切り替える(MMC1・MMC3・AxROM で必要)。
**未検証**: CIRAM A10 を RP2350 の 3.3V で動かして問題ないか。画面の上下左右がつながっておかしい時は、JP1 をはがして JP2 か JP3 にする(その場合ミラーリングは固定)。

| 閉じる所 | ミラーリング | 向いているもの |
|---|---|---|
| JP1(MCU) | ファームウェアが切り替える | すべて(推奨) |
| JP2(V = A10) | 垂直に固定 | 横スクロールのゲーム(マリオなど) |
| JP3(H = A11) | 水平に固定 | 縦スクロールのゲーム |

### ファームウェアを書く

1. Core2350B2 を FPC-USB アダプター経由で PC につなぐ(ファミコンには挿さなくてよい)。
2. 基板の **BOOTSEL を押したまま RESET を押して離す** → PC に「RP2350」ドライブが出る。
3. `FC-MAGICON\firmware\out\` の `.uf2` をそのドライブにコピーする。自動で再起動する。

| ファイル | 使う時 |
|---|---|
| `usb_test.uf2` | USB の速さを測る(ファミコン無しで。`tools/usb_bench.py` と使う) |
| `bus_test.uf2` | 最初の動作確認 1(CPU バス) |
| `chr_test.uf2` | 最初の動作確認 2(PPU の読み取り) |
| `magicon.uf2` | ふだん使う(ゲーム・NSF・リモートデスクトップ) |

### 最初の動作確認(基板を作って最初の 1 回)

1. **モジュールを載せる前に**、テスターで +5V(J4 の 30/60 列)と GND の間がショートしていないか確かめる。
2. `bus_test.uf2` を書き、USB だけつなぐ → LED が速く点滅し、USB シリアルに `waiting for Famicom 5V` と出れば正常。
3. 電源を切ったファミコンに挿して電源を入れる → **ピーという音**が鳴り、LED が約 0.5 秒ごとに点滅すれば、CPU バスの読み書きが動いている。鳴らない時はリセットボタンを押す。
4. `chr_test.uf2` を書いて同じように挿す → **4色の縦縞と、8 ドットごとの白い格子**が出れば、PPU の読み取り(アドレス下位を AD0-7 から読む方式)が成り立っている。模様が崩れる時は、TP1(/RD)と TP2(PPU D0)をオシロで見る。
5. `magicon.uf2` を書く。以後はこれを使う。

## ゲームを遊ぶ

1. Core2350B2 を USB で PC につないだまま(本体の電源は切っても入れてもよい)、PowerShell で実行する:
   `pwsh -File C:\Users\Yugo\OneDrive\ドキュメント\Claude\FC-MAGICON\firmware\load_rom.ps1 ゲーム.nes` 。
   マッパー・大きさを表示し、動くものならフラッシュに書く(magicon が動いていれば、BOOTSEL を押さなくても自動で書き込みモードになる)。
2. ファミコンの電源を入れ直す(またはリセット)。書いた ROM で起動する。
3. ROM はファームウェアを書き直しても消えない。別の ROM を書くまで同じものが起動する。

対応しているマッパー(PRG + CHR の合計 384KB まで):

| 番号 | マッパー | 特徴 |
|---|---|---|
| 0 | NROM | バンク切り替え無し |
| 1 | MMC1 | CHR-RAM も可。ミラーリング切り替え(JP1) |
| 2 | UxROM | CHR-RAM |
| 3 | CNROM | CHR 8KB 切り替え |
| 4 | MMC3 | スキャンライン割り込み(/IRQ)。ミラーリング切り替え(JP1) |
| 7 | AxROM | 1 画面ミラー(JP1) |
| 87 | Jaleco J87 | $6000-$7FFF の書き込みで CHR 切り替え |
| 184 | Sunsoft-1 | $6000-$7FFF の書き込みで CHR 4KB × 2 |

- バッテリーバックアップのセーブ(WRAM)は、**電源を切ると消える**(フラッシュへの保存はまだ)。
- 対応していない ROM を書こうとすると、`load_rom.ps1` がその場で止まる(フラッシュは書き換えない)。
- ROM が入っていない・壊れている時は、chr_test と同じ試験画面になる。理由は USB シリアルに出る。

## NSF(音楽)を聴く

1. ゲームと同じく `load_rom.ps1 曲.nsf` で書き、ファミコンの電源を入れ直す。
2. 曲名・作者・「SONG 01 / 12」の画面が出て、最初の曲が鳴る。

| 1コン | 動作 |
|---|---|
| ← / → | 前の曲 / 次の曲 |
| A | 今の曲を最初から |
| START | 一時停止 / 再開 |

- **拡張音源(VRC6・FDS・N163 など)はまだ鳴らない**。本体の音源(2A03)の分だけ鳴る。
- 再生の間隔が標準(約 60Hz)と違う NSF は、テンポが変わる。

## リモートデスクトップ(PC の画面をファミコンに映す)

### 始め方

1. カセットを画面転送モードにする(1 回だけ。別の ROM を書くまで続く):
   `pwsh -File C:\Users\Yugo\OneDrive\ドキュメント\Claude\FC-MAGICON\firmware\load_rom.ps1 -Remote`
2. キーボードを使うなら、**ファミコンの電源を切った状態で** 拡張端子にファミリーベーシックのキーボードを挿す。
3. ファミコンの電源を入れる → 「FC-MAGICON REMOTE / WAITING FOR PC...」と出る。
4. Core2350B2 を USB で PC につないだまま、PC 側のアプリを起動する:
   `python C:\Users\Yugo\OneDrive\ドキュメント\Claude\FC-MAGICON\firmware\tools\remote_pc.py` 。
   PC の画面がファミコンに映る。止める時は、アプリを動かしている画面で **Ctrl+C**(押しっぱなしのキーとボタンは離してから止まる)。

| オプション | 内容 |
|---|---|
| (なし) | 灰色 4 階調。文字がいちばん読みやすい |
| `--color` | カラー(16 x 16 ドットごとに 4 色、ディザあり) |
| `--port COM5` | COM ポートを指定する(自動で見つからない時) |
| `--fps 30` | 送る速さの上限(既定 30) |
| `--dry-run 30` | カセット無しで、画面の取り込みと変換の速さだけ測る |
| `--tcp` | Wi-Fi ブリッジ(ESP32-C6)経由でつなぐ(既定 25 枚/秒)。**カセット側がまだ対応していない**(下の「Wi-Fi で送る」) |

### 操作(1コン)

| 1コン | PC 側 |
|---|---|
| 十字キー | マウスを動かす(押し続けると速くなる) |
| A / B | 左クリック / 右クリック |
| SELECT | 表示の切り替え: 画面全体を縮小 ⇔ カーソルのまわりを等倍(等倍は文字が読める) |
| START | 等倍の時、表示がカーソルを追うか・止めるか |

### 操作(ファミリーベーシックのキーボード)

前に作った拡張端子 ⇔ USB 変換器(Famicom-Expand-USB-Adapter)と同じ割り当て。

- **SHIFT・GRPH(Alt)・CTR はトグル**: 1 回押すと ON、もう 1 回で OFF。RETURN を押すと SHIFT は自動で OFF になる。
- 記号は日本語(JIS)配列の位置で送る。Windows のキーボード設定が日本語配列であること。
- カナキーは IME の切り替え(半角/全角)。

英字・数字(A〜Z、0〜9)は刻印どおり。それ以外:

| ファミコンのキー | PC で押されるキー | ファミコンのキー | PC で押されるキー |
|---|---|---|---|
| F1 | F1 | ↓ | ↓ |
| F2 | F2 | ESC | Esc |
| F3 | F3 | GRPH | Alt(トグル) |
| F4 | F4 | INS | Insert |
| F5 | F5 | カナ | 半角/全角 |
| F6 | F6 | ← | ← |
| F7 | F7 | SHIFT(左) | Shift(トグル) |
| F8 | F8 | RETURN | Enter |
| , | , | → | → |
| - | - | SHIFT(右) | Shift(トグル) |
| . | . | SPACE | Space |
| / | / | STOP | BackSpace |
| : | : | ↑ | ↑ |
| ; | ; | ¥ | ¥ |
| @ | @ | [ | [ |
| CLR HOME | Home | ] | ] |
| CTR | Ctrl(トグル) | ^ | ^ |
| DEL | BackSpace | _ | ろ(バックスラッシュ) |

### 速さの目安(この PC、2026-09-27)

| 表示 | 灰色 | カラー |
|---|---|---|
| カーソルのまわりを等倍 | 約 60 枚/秒 | 約 60 枚/秒 |
| 画面全体を縮小 | 約 30 枚/秒 | 約 23 枚/秒 |

PC 側の取り込みと変換だけの値。USB 直結は 614KB/秒(最大 40.6 枚/秒)出るので、画面を作る PC 側の速さで決まる
(Core2350B2 単体で測定。`remote_pc.py` を流して 灰色 29.8 枚/秒、カラー 20.0 枚/秒)。

### Wi-Fi で送る(ESP32-C6、作りかけ)

**カセット側のファームウェアがまだ対応していない**(RP2350 を USB ホストにする所が未実装)。C6 と PC の間は動いている。

1. C6 に Wi-Fi の設定を書く: `firmware\wifi_bridge\wifi_secrets.example.h` を写して `wifi_secrets.h` にし、SSID とパスワードを書く(2.4GHz)。
2. C6 を PC につないで書き込む: `pwsh -File C:\Users\Yugo\OneDrive\ドキュメント\Claude\FC-MAGICON\firmware\wifi_bridge\build_bridge.ps1`
3. (カセット側が対応したら)C6 と J6 を 3 本でつなぐ: J6 の 2 番(D-)→ C6 の GPIO12、3 番(D+)→ GPIO13、4 番 → GND。C6 の電源は別の USB から取る。FPC-USB アダプターは外す。
4. PC で `python C:\Users\Yugo\OneDrive\ドキュメント\Claude\FC-MAGICON\firmware\tools\remote_pc.py --tcp`

| 項目 | 値(2026-09-27、PC をカセットの代わりにして測定) |
|---|---|
| 最大の速さ | 462KB/秒 = 30.6 枚/秒 |
| 25 枚/秒で送った時の遅れ | 中央 37ms、最大 81ms |
| `remote_pc.py --tcp` で流した時 | 灰色 24.5 枚/秒、カラー 19.9 枚/秒 |

- C6 が動かない・Wi-Fi につながらない時は、C6 の USB を挿し直す(電源が弱いボードで、ブラウンアウトでリセットを繰り返すことがある)。

## 困ったとき

| 症状 | 見る所・やること |
|---|---|
| 画面が出ない・音が鳴らない | 本体のリセットを押す(カセットの起動が本体に間に合わなかった可能性)。USB シリアルに理由が出ていないか見る |
| `waiting for Famicom 5V` のまま | 本体の電源が入っていない、またはカセットが奥まで挿さっていない |
| 画面の上下・左右のつながりがおかしい | ジャンパー(JP1〜3)を見直す。JP1 で駄目なら JP2 / JP3 |
| `load_rom.ps1` が書き込めない | BOOTSEL を押したまま RESET を押して離してから、もう一度実行する |
| `COM ポートが見つからない` | USB ケーブル・FPC の向きを確認。`--port COMx` で指定する |
| キーが押しっぱなしになった | アプリを Ctrl+C で止める(全部離す)。USB が 0.5 秒途切れた時も自動で離す |
| 記号キーがずれる | Windows のキーボードが日本語配列になっているか確認する |
| キーボードの文字が抜ける・二重になる | 拡張端子の挿し込みを確認。読み取りの待ち時間は 500us(`gen_remote_driver.py` の KB_WAIT_US) |
