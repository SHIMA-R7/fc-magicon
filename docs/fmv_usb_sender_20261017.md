# FMV / Windows 11：USB直結リモートデスクトップ

これはr1の記録。r2の変更・操作は `fmv_usb_sender_r2_20261017.md` を参照。

配布ZIPは全部展開し、`FC-MAGICON-USB/FC-MAGICON-USB.exe`を開く。Pythonのインストールは不要。EXEだけをフォルダから取り出さない。

転送用ZIPの作業フォルダ内の場所：`output/FC-MAGICON-USB-Win11-20261017.zip`（リポジトリの1つ上の作業フォルダ）。元の配布成果物は `firmware/out-usb-sender/win11-20261017-191847/FC-MAGICON-USB-Win11.zip`。

1. RP2350基板をFMVへデータ通信対応のUSBケーブルで接続する。
2. FCをONにして、アプリの「再検索」を押し、基板のCOMポートを選ぶ。今回のファームはFC側の起動後にUSBシリアルを有効にするので、FCがOFFの間はCOMが出ない。
3. ブルーアーカイブをメイン画面に表示し、「転送開始」。アプリは最小化される。映像はメイン画面全体、音声は既定出力の再生音が対象。
4. タスクバーから戻して「停止」で転送を終了する。ログは `%LOCALAPPDATA%/FC-MAGICON/usb-*.log`。

既定はカラー、8fps上限、4:3全画面、PCM8・32kHzモノラル。変換速度によって実際のfpsは低くなる。点模様による混色はOFF。PC側で色を考慮して256パターンへ近似する。単独動画完成版のオフライン境界最適化とは異なり、リアルタイム向けの既存タイル近似を使う。

十字キーでマウス移動、Aで左クリック、Bで右クリック。SELECTで全体／カーソル周辺拡大、STARTで拡大時の追従切替。感度は以前の半分設定を維持し、カーソルは画像へ小さく描く。今回の受信ドライバーはパッド入力のみで、ファミリーベーシックのキーボードは未対応。

受信ファームは `remote-desktop-usb-a9-gpio39-20261017.uf2`。A9をGPIO39へ移設済み・LED撤去済みの現基板向け。完成した単独動画版の起動処理・高速CPU応答・PPU DMAを引き継ぎ、USB受信と成功したPIO音声経路を追加した比較版。USBホスト／C6用ファームではない。単独動画データはフラッシュの+8MiBに残す。

FCFR/FCAUを受信し、完成フレームを7 VBlankで切り替えるため、更新上限は約8.5fps。動画版と違ってUSB処理が入るので、今回の実機確認が必要。無線版の旧配布物 `FC-MAGICON-WiFi-Win11.zip` と区別する。

ソース版：`firmware/tools/remote_pc.py --port COM番号 --color --stretch --fps 8 --audio pcm8 --solid --fit-tiles --software-cursor`

画面と再生音の送信だけで録画ファイルは作らない。管理者権限は通常不要だが、高権限で起動したゲームへの入力が届かない場合がある。ゲーム保護を回避する機能はない。

## 検証範囲

RP2350向けビルド成功。実際のCカート処理で、PC側で256タイルへ変換した3シーンについて、FCFRコミット後の絵・属性・高速パレット応答・表示待ちの上書き拒否・表裏の交互切替を確認。共通の6502ドライバーは全792コマの切替・起動待機・最大1779 CPUサイクル・PCMリングの既存検査を再実行して通過した。

配布EXEはローカル模擬受信先へ実画面3フレーム・PCM8音声13パケットを送信し、停止要求で終了コード0。これは実機USB接続・FMV上の動作や聴感の確認ではない。C6／Wi-Fi版との統合は別作業。

ユーザーのFC OFF・BOOTSEL準備完了返答後、受信ファームを書き込み、全領域照合でOK、再起動コマンドも成功。動画データの+8MiB領域は書き換えていない。書込み記録は `firmware/out-standalone-video/remote-desktop-usb-a9-gpio39-20261017.json`。USB直結での実機再生は確認待ち。
