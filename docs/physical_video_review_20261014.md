# ブルアカ7thPV-4fps-2 実機録画の確認

対象は作業フォルダの `ブルアカ7thPV-4fps-2.mp4`（33.09秒）。前の `ブルアカ7thPV-4fps-1.mp4`（49.53秒）も比較した。ユーザーの説明により、4:3から16:9に拡大する外部コンバーターの横伸びは不具合として扱わない。録画だけでは再生時のファームウェア・転送方式・USB給電有無までは特定しない。

## 観察

- 12秒付近の信号機、20秒付近の人物、背景建物などが判別しやすい。
- 複雑な場面では細部が単色の大きな領域に置き換わる。減色・タイル数削減による表現損失が残る。
- 22.5〜24秒を0.125秒間隔で確認。23.375〜23.500秒付近では、人物の腕付近を横切る大きな黒い矩形が見える。画面更新に関係する可能性があり、すべてを変換による画質制限と決めつけない。
- 現在の4:3補正済み30秒版の保存フレームも参照した。同種の場面にこの大きな黒い矩形は見えない。ただし録画の再生元と時刻対応を厳密には同定していないため、現行ファームウェアの不具合と断定はしない。
- 録画には音声ストリームがあるが、16kHzモノラル復号の全体RMSは28.39/32768と小さい。これだけで音楽の連続再生や同期を確認したとは扱わない。

確認用画像は `firmware/sim/standalone-video-20261014/physical-4fps-2-contact.jpg` と `physical-4fps-2-transition.jpg`。画像のタイムスタンプは録画開始からの時刻で、元PVの時刻ではない。

追加の書き込み・再生は行っていない。
