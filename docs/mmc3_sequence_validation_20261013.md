# MMC3の段階的なオフライン検証（2026-10-13）

実機への書込みはしていない。以下は、実機不在で行った四段階の検証結果。前の `mmc3_retroarch_validation_20261013.md` にある走査線試験の不合格は、今回のサイクル単位の試験台では解消した。

## 1. 同じ入力でタイトル・マップ・ステージを比較

RetroArch用の公式Nestopia libretroコアを専用Pythonフロントエンドから駆動した。入力は `firmware/sim/mmc3-sequence-20261013/inputs.json` に保存。START後、ユーザー指定の「右、上、A」でステージへ入り、B+右と複数回のジャンプまで3900フレーム実行した。agnesベースの試験台ではステージの一部に差があり、時間の進め方の差と実装の差を分離するため次の段階へ進めた。

## 2. サイクル単位のIRQ比較

NestopiaのCPU・PPU・バンク切替を保持し、IRQカウンターだけを実際の `magicon/cart.c` に置き換えた検証専用コアをビルド。A12の資格判定はM2三周期のモデルで行う。通常利用・セーブステート用のコアではない。

[MMC3 IRQテストROM](https://github.com/christopherpow/nes-test-roms/tree/master/mmc3_irq_tests) の1、2、3、4、6が合格。4の厳密な走査線時刻も合格した。5はRevision A向けで、Revision Bを対象とする今回の実装では不合格。

同じ入力のマリオ3は、標準Nestopiaと検証コアの **3900フレームすべてのRGBハッシュが一致**。結果は `strict-all-frame-results.json`。これはカウンターの論理と理想的な資格判定の検証であり、実機のGPIO、PIO、IRQ処理遅延、CHRコピーを保証しない。

## 3. CHRコピー時間を加える

検証コアに8KiBのCHRキャッシュを追加し、変更された1KiBバンクを順に、その場で更新する遅延モデルを実装した。速度は一定と仮定し、コピー中の読出しは古い値または更新途中の値を返す。実際のARM命令・割込み・SRAM競合を実行するモデルではない。実測最大21µsをすべてのコピーに適用する試験は保守的な条件。

| 1KiBのコピー時間 | 標準から異なるフレーム数／3900 | 最初の差のフレーム | 即時切替と異なるCHR読出し数 |
|---|---:|---:|---:|
| 0µs | 0 | — | 0 |
| 10µs | 11 | 3556 | 235 |
| 21µs | 904 | 2467 | 3972 |
| 42µs | 907 | 2467 | 9978 |

21／42µsでは下部HUDの小さな文字・数字の化けが見える。実機の大きな崩れをすべて再現したわけではない。結果は `delay-results.json`、比較画面は `copy-delay-comparison.png`。コピー中の描画を無視できない証拠であり、実機の単独原因の確定ではない。

## 4. FIFO・遅延・競合

PIO命令モデルにRX容量とARM側の読出し時刻を追加。`tests/test_pio_backpressure.py` が合格。

- A12の結合RX FIFOは8ワード。20イベントを無処理で入力すると8件を保持し、`push noblock` により12件を失う。適時に読めば20件すべてを保持。
- CPUのRX FIFOは4ワード。満杯では `push block` が停止する。書込みバスを駆動しないこと、適時にFIFOを読めば取引が進むことを確認。
- 既存の遅い応答・期限超過・書込みデータ保持試験、140相対位相のA12資格試験も合格。
- 実際のCコードの256バンク配置、独立した既知配置、IRQリロード競合、世代番号折返し、WRAM保護試験も合格。

これらは異常が起こる条件の確認。実機でFIFOが満杯になっているとは未確認。次回はFIFO深さ・サービス間隔のログと、CHRコピーの影響を分離して測定する。資格判定を通らないはずの短い実機イベントが多い問題も残っており、理想波形モデルの合格だけでは解決しない。

## 再現用ファイル

`firmware/sim/mmc3-sequence-20261013/` の `run_nestopia.py`、`build_nestopia_counter.py`、`nestopia_counter_bridge.c` と、`ref/nestopia-timing/nestopia-master/` の検証用変更ソースを保存した。実機用の未書込みUF2は `firmware/out-direct-pio-diagnostic/magicon-mmc3-reload-generation.uf2`。現在の実機はリモート表示用なので、MMC3に戻す際にはマリオ3のROM領域も書き戻す必要がある。
